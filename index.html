01 / The project

Built for the bench.

Pocket Drift: Overdrive pairs miniature GT-style cars with oversized workshop tools and a purpose-built circuit. Developed in Unity by Casper under Branded Creations 2026, it brings big motorsport energy to a tiny racing world.

02 / Public beta download

Get on the grid.

Download the complete Windows 64-bit v3.1 beta as one 38.6 MB ZIP. Unity and a separate installer are not required.

Install in four steps

  1. Download the beta ZIP using the official button.
  2. Extract the entire ZIP into a new folder.
  3. Keep the EXE, Data folder, UnityPlayer.dll, and MonoBleedingEdge together.
  4. Run Pocket Drift Overdrive.exe. If SmartScreen appears, verify that this is the official project download before continuing.

Windows beta v3.1

Requires 64-bit Windows 10 or Windows 11. Keyboard and gamepad are supported.

Download 38.6 MB
  • Drive: WASD or arrow keys
  • Drift / boost: Space / Left Shift
  • Weapon: E / Enter / left mouse
  • Respawn: R
