# Pocket Drift website

Static responsive website. Open index.html locally or serve this directory with a static server. No build dependencies, analytics, external fonts, or personal-data collection. Upload the entire website directory to a static host when publishing is authorized.

## Editing

- index.html: game copy, creator section, updates, and beta status.
- style.css: responsive layout, colors, and typography.
- assets/circuit.png: existing Unity scene capture copied from Blender/workshop-pro-unity.png.
- assets/cars.png: existing Blender studio render copied from Blender/workshop-pro-cars.png.

The date denotes the prepared development snapshot, not a claim that the art was completed that day. Original project documentation is WORKSHOP-PRO.md.
